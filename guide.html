🎮 Game Boy Synthesis in Strudel

The strudel-gb plugin binds Game Boy hardware-based synthesis to the Strudel Live Coding environment. Behind the scenes, the sound engine compiles a C-based emulator into WebAssembly, running on an isolated browser audio thread.

💡
Interactive Mode: Click the "Boot Audio Engine" button at the top of this page to activate the APU simulator. Once online, you can click on the "▶ Demo" button next to any instrument below to hear it in real-time!

  .s("gb.lead")
  .fast(2)

🔊 Predefined Instruments & FX Catalog

Drums and complex presets are registered as full synthesizer instruments. You can select them directly in Strudel using .s("instrument-name").

⚙️ Hardware Register Parameters Reference

For expert sound design, chain these parameters onto your Strudel pattern to adjust raw hardware parameters.

Parameter Type Valid Values Description
.channel(val) String "pulse1", "pulse2", "wave", "noise" Directs the notes to play on specific Game Boy hardware channels.
.duty(val) Number 12.5, 25, 50, 75 Set Pulse Wave duty cycle width (thin, classic, hollow, biting). Pulse 1/2 only.
.volume(val) Number 0 to 15 (Wave: 0, 1, 2, 3) Sets the initial channel volume level.
.envelope(obj) Object { initial, direction, pace } Sets initial volume (0-15), direction ("down"/"up"), and pace time (0-7).
.pitchSweep(obj) Object { rate, amount } Sets sweep rate (0-7) and pitch glide direction/shift amount (+/- 7). Pulse 1 only.
.waveTable(val) Str/Arr "sine", "sawtooth", custom hex, or 32-number array Writes custom 4-bit wavetable samples (0-15) for the Wave channel.
.lfsr(val) Number 7, 15 Sets Noise shift register bit-width (7 = metallic/tonal, 15 = white noise).
.frequency(val) Obj/Num { shift, dividing } or raw byte Configures Noise generator clock multiplier and divisor ratio.
.arp(arr) Array/Str [0, 4, 7], "0 3 7" Fakes chord polyphony in the audio thread using high-speed arpeggiation offsets.
.pan(val) Number -1 (Left) to 1 (Right) Stereo panning using NR51 channel pan mapping (Left/Center/Right).

📝 Advanced Composition Recipes

1. Classic Stereo Counterpoint

Pan two pulse leads opposite ways to create a wider stereo image.

stack(
  note("C4 E4 G4 B4").s("gb.lead").pan(-0.8).arp([0, 7]),
  note("E3 G3 B3 D4").s("gb.pad").pan(0.8).tags("nasal")
)

2. Game Boy Drum Loop

Create a full chiptune loop using pre-routed percussion instruments.

stack(
  note("C4").s("gb.kick").struct("1 0 0 0 1 0 0 0"),
  note("C4").s("gb.snare").struct("0 0 1 0 0 0 1 0"),
  note("C4").s("gb.hihat").struct("1 1 1 1 1 1 1 1")
)
