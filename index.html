strudel-gb

A premium Game Boy APU sound synthesis suite integrated with Strudel Live Coding. Synthesize retro audio via hardware parameters, compose chiptune loops, and explore.

🎮

Hardware Playground

Directly manipulate Game Boy registers using virtual hardware sliders. Layer preset instruments, adjust duty cycles, and watch real-time waveforms in a Game Boy visualizer.

Open Playground
⚡

Composition REPL

Write chiptune compositions using Strudel live-coding syntax. Use custom instruments like .s("gb.lead"), program drum patterns, and trigger notes in code.

Open REPL
📖

Reference Guide

Browse the complete chiptune preset catalog, test sound previews in your browser, copy code snippets, and review register parameters and composition recipes.
